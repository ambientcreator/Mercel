# Mercel

Mercel — это desktop-приложение на Wails для расчёта услуг, автоматического сохранения расчётов в архив SQLite и работы с пользователями по ролям и отделам.

## Что умеет приложение

- Выполняет точный расчёт суммы по текущему набору услуг пользователя.
- Поддерживает группы услуг: `Основная`, `Вторичная`, `Закрывающая`.
- Позволяет задавать веса услуг от `0` до `10`.
  Один шаг веса добавляет приоритет услуги внутри её группы.
- Автоматически сохраняет расчёт в архив сразу после нажатия `Рассчитать`.
- Для архива использует текущую дату в формате `дд.мм.гггг` как название записи.
- Если за текущий день у пользователя уже есть архивная запись, она перезаписывается, а не дублируется.
- Хранит отдельный список услуг для каждого пользователя.
- Показывает архив в зависимости от прав доступа и отдела.
- Позволяет создавать, редактировать и удалять услуги прямо из интерфейса.
- Позволяет создавать пользователей и управлять ролями в рамках разрешённой зоны ответственности.

## Логика расчёта

- Сумма вводится вручную.
- После нажатия `Рассчитать` приложение:
  - считает комбинацию услуг,
  - показывает результат,
  - сразу сохраняет его в архив.
- Поле даты подставляется автоматически и недоступно для редактирования.
- Проценты по группам по умолчанию:
  - `Основные` — `79%`
  - `Вторичные` — `20%`
  - `Закрывающие` — `1%`
- Если у конкретной услуги не задан свой процент, доля группы делится равномерно между услугами этой группы.
- Вес влияет только внутри своей группы и помогает смещать приоритет распределения.

## Отделы и роли

В приложении есть 3 независимых направления ролей.

### Техническая поддержка

- `Руководитель Тех. Поддержки`
- `Старший Специалист Тех. Поддержки`
- `Сотрудник Тех. Поддержки`

### Технический отдел

- `Руководитель Технического отдела`
- `Старший Техник`
- `Техник`

### МРК

- `Руководитель МРК`
- `Старший МРК`
- `МРК`

### Администратор

- `Администратор`

## Разграничение доступа

- `Администратор` видит все отделы, всех пользователей и весь архив.
- Руководитель видит только свой отдел и только подчинённые роли внутри этого отдела.
- Старший сотрудник видит только младшую роль своего отдела.
- Пользователи одного отдела не видят архивы и сотрудников другого отдела.
- Список услуг у каждого пользователя свой собственный.
- При удалении пользователя его архивные записи не пропадают.

## Архив

- Архив хранится в SQLite.
- Каждая запись содержит:
  - дату,
  - автора,
  - роль автора на момент сохранения,
  - итоговую сумму,
  - состав услуг.
- Если пользователь удалён, архив остаётся доступным по правилам видимости.
- В архиве можно удалять записи с подтверждением через встроенное модальное окно.

## Требования

- Go `1.26+`
- Wails CLI `v2`
- WebView2 Runtime для Windows

Установка Wails CLI при необходимости:

```powershell
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

## Запуск в режиме разработки

```powershell
wails dev
```

## Сборка

```powershell
wails build
```

Готовый `.exe` после сборки:

- `build/bin/Mercel.exe`

## Тесты

Запуск backend-тестов:

```powershell
go test ./...
```

Проверка frontend-скрипта на синтаксис:

```powershell
node --check frontend/dist/assets/app.js
```

Текущее покрытие Go-кода тестами — около `70%` операторов.

## База данных

Текущий путь к базе данных:

- `C:\Users\<username>\AppData\Roaming\Mercel\mercel.sqlite`

Старый путь, откуда приложение умеет восстанавливать данные после переименования:

- `C:\Users\<username>\AppData\Roaming\Statistic\statistic.sqlite`

## Важные примечания

- Frontend встроен прямо в приложение.
- После изменений во frontend лучше полностью перезапускать `wails dev`.
- `frontend/wailsjs` генерируется автоматически и не нужен в git.
- `build/bin` содержит локальные артефакты сборки и обычно не коммитится.
