# Mercel

Mercel - это desktop-приложение на Wails для точного расчёта услуг, сохранения расчётов в SQLite и управления пользователями с разграничением прав доступа.

## Возможности

- Точный расчёт суммы по пользовательскому набору услуг
- Разделение услуг на группы: основные, вторичные, закрывающие
- Поддержка весов и процентного распределения по услугам
- Сохранение расчётов в архив SQLite
- Работа с несколькими пользователями и ролями
- Изолированные списки услуг для каждого пользователя

## Стек

- Go
- Wails v2
- SQLite
- Встроенный frontend на HTML/CSS/JavaScript

## Роли

- Администратор
- Руководитель
- Старший специалист ТП
- Специалист Тех. Поддержки

Права на управление пользователями, доступ к архиву и удаление зависят от текущей роли.

## Требования

- Go `1.26+`
- Wails CLI `v2`
- WebView2 Runtime для Windows

Установка Wails CLI при необходимости:

```powershell
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```

## Запуск в режиме разработки

```powershell
wails dev
```

## Сборка

```powershell
wails build
```

Готовый `.exe` после сборки:

- `build/bin/Mercel.exe`

## Тесты

Запуск backend-тестов:

```powershell
go test ./...
```

Текущее покрытие Go-кода тестами - около `70%` операторов.

## База данных

Текущий путь к базе данных:

- `C:\Users\<username>\AppData\Roaming\Mercel\mercel.sqlite`

Старый путь, который приложение умеет автоматически восстанавливать при необходимости:

- `C:\Users\<username>\AppData\Roaming\Statistic\statistic.sqlite`

## Примечания

- Frontend хранится в `frontend/dist` и встраивается прямо в исполняемый файл
- `frontend/wailsjs` генерируется автоматически и не нужен в git
- `build/bin` игнорируется, потому что содержит локальные артефакты сборки
